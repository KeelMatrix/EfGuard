# EFG304 — Unbounded data backfill

## When it triggers

An `UPDATE`-shaped SQL operation has no detectable `WHERE` clause.

## Why it matters

The migration may update every row in one operation, extending locks and transaction time or increasing operational recovery risk.

## Remediation

Move the backfill to bounded, resumable, throttled application or operational work with progress tracking.

## Limitations

The rule relies on local SQL classification. EfGuard does not execute or transmit the SQL and cannot prove the actual rows affected by an operation whose predicate is not detectable.

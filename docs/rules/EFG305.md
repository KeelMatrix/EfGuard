# EFG305 — Transaction semantics require review

## When it triggers

An operation suppresses its transaction.

## Why it matters

The operation does not share the migration's normal atomicity boundary, so partial application or provider-specific transaction requirements may affect deployment safety.

## Remediation

Isolate the operation from changes that require atomicity and verify provider and deployment behavior before applying it.

## Limitations

This finding is independent of SQL semantic classification: arbitrary SQL can also retain EFG399, and an unbounded backfill can also retain EFG304. The rule does not prove that the surrounding deployment sequence is safe.

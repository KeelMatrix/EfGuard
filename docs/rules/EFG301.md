# EFG301 — Potentially blocking SQL Server index creation

The SQL Server index is not marked online. When exactly one provider-generated SQL statement is tied to the normalized operation and has the expected `CREATE INDEX` shape for its table, it is retained in `providerSql` as evidence; runtime lock duration still depends on engine edition, version, index shape, workload, and deployment conditions. Missing, ambiguous, unrelated, or shape-mismatched SQL leaves this finding explicitly `UNVERIFIED`. Configure online creation where supported or schedule a maintenance window, and validate the actual engine behavior separately.

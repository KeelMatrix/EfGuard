# EFG900 — Unsupported database provider

## When it triggers

The selected EF Core project uses a provider other than SQL Server/Azure SQL or Npgsql PostgreSQL.

## Why it matters

Provider locking and compatibility behavior differ, so EfGuard cannot make a trustworthy provider-specific claim for an unsupported provider.

## Remediation

Use a supported provider for v1 analysis, or treat the result as an execution failure and review the migration with provider-specific tooling.

## Limitations

EfGuard does not infer provider behavior from another provider. Unsupported providers produce an unverified result and exit with code `2`.

# EFG399 — Unverified operation or compatibility history

Raw SQL and custom operations are outside the high-confidence semantic rules. Review SQL and rollout order manually. Unknown operations are never treated as safe.

EfGuard also reports this diagnostic when a rolling policy requests more than one compatible application generation but the scan does not contain enough baseline history. Supply the available baseline history or reduce `minimumCompatibleVersions` to match the evidence. Missing history is never inferred as compatible.

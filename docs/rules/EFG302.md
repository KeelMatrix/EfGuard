# EFG302 — Write-blocking PostgreSQL index creation

The PostgreSQL index is not configured for concurrent creation. When provider-generated migration SQL for the operation is available, it is retained in `providerSql` as evidence; workload-dependent lock and wait behavior remains uncertain. Without matching generated-SQL evidence, this finding is explicitly `UNVERIFIED`. Use the Npgsql concurrent option when appropriate and honor its transaction requirements, then validate the actual engine behavior separately.

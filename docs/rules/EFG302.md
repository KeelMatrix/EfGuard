# EFG302 — Write-blocking PostgreSQL index creation

The PostgreSQL index is not configured for concurrent creation. When exactly one provider-generated SQL statement is tied to the normalized operation and has the expected `CREATE INDEX` shape for its table, it is retained in `providerSql` as evidence; workload-dependent lock and wait behavior remains uncertain. Missing, ambiguous, unrelated, or shape-mismatched SQL leaves this finding explicitly `UNVERIFIED`. Use the Npgsql concurrent option when appropriate and honor its transaction requirements, then validate the actual engine behavior separately.

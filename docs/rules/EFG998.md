# EFG998 — Expired suppression

## When It Triggers

The configured expiry date for a suppression has passed.

## Why It Matters

The suppression no longer represents a current exception, so the original finding remains active and the configuration itself is blocking.

## Remediation

Renew the suppression only with a current, documented rollout reason, or fix the original finding.

## Limitations

EFG998 reports the expired suppression; it does not replace or suppress the original diagnostic.

# EFG201 — Destructive change

## When it triggers

The migration drops a column or table.

## Why it matters

The operation can permanently remove data and reduce rollback or recovery options. It can also break application generations that still depend on the object.

## Remediation

Preserve a recoverable copy, retire dependent application generations, and perform the drop only as a later contract step in an expand/transition/contract rollout.

## Limitations

EfGuard does not inspect database contents, backups, or live application usage. EFG101 covers the model-compatibility consequence when baseline evidence is available.

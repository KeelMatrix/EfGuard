# EFG204 — Unique index/constraint validation risk

## When it triggers

The migration creates a unique index or unique constraint.

## Why it matters

Existing duplicate values can make validation fail and can delay deployment while the database checks the constraint.

## Remediation

Validate and repair duplicate data before enforcing uniqueness, then apply the index or constraint during a controlled transition.

## Limitations

EfGuard does not connect to the database or inspect existing values. Verify duplicates and provider-specific validation behavior separately.

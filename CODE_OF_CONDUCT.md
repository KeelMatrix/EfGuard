# Code of Conduct

Contributors are expected to be respectful, constructive, and inclusive. Harassment, discrimination, threats, and intentional disruption are not acceptable.

## Reporting conduct concerns

Report abusive, harassing, or otherwise unacceptable behavior in the project's public spaces through the GitHub issue tracker so maintainers can review and moderate it. If the behavior occurs on GitHub, use GitHub's built-in reporting tools when appropriate.

Conduct reports are distinct from vulnerability reports. Do not use the security reporting route for conduct concerns; security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be disclosed publicly.
